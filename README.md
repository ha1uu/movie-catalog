# Кадр — каталог фильмов

Медиапортал на **Nuxt 3**, Vue 3 и TypeScript. Главная, каталог, страницы фильмов и персон рендерятся на сервере. Включает 12 фильмов и 7 персон; ключи API, база данных и сторонние сервисы не нужны.

## Запуск

Нужен Node.js 22 или 24 и npm. В облачной среде используйте существующий каталог `/workspace/movie-catalog`.

```bash
npm ci
npm run dev
```

Dev-сервер слушает `0.0.0.0:3000`. Production:

```bash
npm run typecheck
npm run build
NITRO_HOST=0.0.0.0 NITRO_PORT=3000 npm start
```

Остановите dev-сервер перед сборкой: Nuxt блокирует одновременную сборку в одном рабочем каталоге.

## Возможности

- SSR-каталог, SEO-метаданные, JSON-LD Movie и настоящие HTTP 404.
- Серверный `useFetch` с передачей данных при гидратации; следующие страницы загружаются через `$fetch`.
- Infinite scroll через IntersectionObserver, порции по 6 фильмов, кнопка ручной подгрузки, конец выдачи, повтор запроса при ошибке и отмена устаревшей подгрузки при смене фильтров.
- Жанры, годы, поиск по русскому и оригинальному названию, сортировка. Фильтры записываются в URL и восстанавливаются при перезагрузке.
- Skeleton-состояния, фиксированное соотношение сторон изображений, место под следующую порцию и ленивые постеры. `font-display: optional` предотвращает сдвиги при поздней загрузке шрифта.
- Избранное в `localStorage`, синхронизированное между страницами текущей вкладки.
- Биографии, фильмографии и связанные переходы между фильмами, актёрами и режиссёрами.
- Адаптивная сетка, клавиатурная навигация, ссылки обхода меню, подписи кнопок и поддержка reduced motion.

Каталог является конечной демонстрационной подборкой: после 12 фильмов подгрузка завершается. Расширьте `server/data/catalog.ts` или замените серверный источник данных для подключения полноценного каталога. Учётные записи, видеоплеер, стриминг и live-обновления в эту версию не входят.

## Проверки

На запущенном production-сервере:

```bash
npm test
npm run test:perf
```

Playwright использует `/usr/bin/chromium`. Другой установленный Chromium можно указать через `CHROMIUM_PATH`; адрес сервера — через `TEST_BASE_URL`.

Функциональные проверки: SSR без JavaScript, фильтры и пустые результаты, поиск, переходы, бесконечная подгрузка без дублей, сохранение избранного, мобильная навигация, восстановление после ошибки API и 404.

Performance-проверка: новый browser context для каждой страницы, отключённый HTTP-кеш, 1,6 Мбит/с, задержка 150 мс, замедление CPU ×4. Измеряет FCP, LCP и CLS через PerformanceObserver. Проверяет FCP < 1500 мс и CLS ≤ 0,01. Это лабораторный замер на локальном production-сервере, а не гарантия скорости хостинга; повторите его после развёртывания.

## Структура

- `pages/` — главная, каталог, фильмы, персоны, избранное.
- `components/CatalogFeed.vue` — фильтры, первая SSR-порция и бесконечная лента.
- `server/api/` — чтение и фильтрация каталога.
- `server/data/catalog.ts` — демонстрационные данные.
- `public/images/`, `public/fonts/` — локальные оптимизированные ресурсы.
- `tests/` и `scripts/performance.mjs` — браузерные и performance-проверки.

Происхождение изображений и шрифтов описано в [ASSETS.md](ASSETS.md).
