# Данные и ресурсы

Фильмы, постеры, кадры, портреты и биографии запрашиваются из [TMDB](https://www.themoviedb.org/) и его сервиса изображений. Прежние локальные постеры и фон удалены. В footer размещена атрибуция TMDB и требуемое уведомление: “This product uses the TMDB API but is not endorsed or certified by TMDB.” Перед публичным запуском соблюдайте [условия использования API и брендирования](https://developer.themoviedb.org/docs/attribution); для коммерческого использования может потребоваться отдельная лицензия.

Нейтральный placeholder постера (`public/images/poster-placeholder.svg`) и CSS-аватары созданы для приложения и показываются только при отсутствии или ошибке загрузки изображения.

Manrope получен из npm-пакета `@fontsource/manrope`, лицензия SIL Open Font License 1.1 в `public/fonts/OFL.txt`. Латинские и кириллические начертания 400, 600, 700 и 800 остаются локальными.

Данные в `tests/fixtures/` предназначены только для воспроизводимых интеграционных проверок и не используются в рабочем каталоге.
