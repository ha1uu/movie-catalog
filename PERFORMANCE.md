# Результаты проверки

Дата: 17 ноября 2026 года. Production-сборка Nuxt 3.21.11, Node.js 24.22.1, Chromium в облачной среде. Для каждой страницы создан новый контекст браузера, HTTP-кеш отключён. Эмуляция: загрузка 1,6 Мбит/с, задержка 150 мс, CPU ×4, viewport 1365 × 900. Сервер расположен на этой же машине.

| Страница | FCP | LCP | CLS |
| --- | ---: | ---: | ---: |
| Главная `/` | 368 мс | 1256 мс | 0 |
| Фильм `/movies/free-guy` | 360 мс | 2256 мс | 0 |
| Персона `/people/ryan-reynolds` | 536 мс | 536 мс | 0 |

Критерий FCP < 1500 мс выполнен на трёх проверенных страницах; при первоначальной загрузке сдвигов макета не зафиксировано. Это лабораторный замер, а не полевые данные: задержка реального хостинга, CDN и устройства пользователей могут изменить результат.

Выполнены `npm ci`, `npm run typecheck`, `npm run build`, `npm test` (8 из 8 сценариев) и `npm run test:perf`. Проверены настольная и мобильная раскладки 1440 и 390 пикселей. Главная, фильм и персона открываются без JavaScript; в браузерной проверке основных страниц ошибок JavaScript и ошибок консоли не обнаружено.

Воспроизведение: запустите production-сервер и выполните `npm run test:perf`. Не используйте dev-сервер для оценки производительности. Функциональные тесты запускаются отдельно командой `npm test`.
